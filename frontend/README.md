# ProjectForge Simple GUI Prototype

This is a deliberately simple front-end prototype for the EPE 321 Group Design Document.

It focuses on:
- basic page layout,
- simple navigation,
- login and sign-up screens,
- placement of the main ProjectForge features,
- a dark/red ProjectForge visual theme.

It does **not** implement the real backend, database or authentication yet.

## Run

1. Open a terminal in this `frontend` folder.
2. Install dependencies:

```bash
npm install
```

3. Start the prototype:

```bash
npm run dev
```

4. Open the local URL shown by Vite.

## Prototype login

Any non-empty email and password will log in.

Use **View Public Showcase** on the login screen to preview the visitor-facing showcase without logging in.
